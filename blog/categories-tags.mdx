Рубрики и теги — два взаимодополняющих инструмента для структурирования публикаций в блоге. Рубрики задают основную тематическую иерархию: каждая статья принадлежит ровно одной рубрике, и их набор обычно невелик и стабилен. Теги, напротив, работают как свободные метки — одна статья может иметь несколько тегов, и новые теги появляются по мере необходимости. Вместе они создают удобную систему навигации, которая позволяет читателям быстро находить материалы по интересующей теме.

## Создание рубрики

Рубрики создаются заранее в разделе управления блогом и затем назначаются статьям при редактировании. Продумайте структуру рубрик до начала публикаций — переименование рубрик в будущем может потребовать обновления уже опубликованных материалов.

<Steps>
  <Step title="Открыть раздел «Блог»">
    В административной панели портала выберите раздел **Блог** в левом меню навигации.
  </Step>
  <Step title="Перейти в «Рубрики»">
    На странице блога откройте вкладку **Рубрики**. Здесь отображается список всех существующих рубрик с количеством привязанных публикаций.
  </Step>
  <Step title="Нажать «Новая рубрика»">
    Нажмите кнопку **Новая рубрика** в правом верхнем углу страницы. Откроется форма создания рубрики.
  </Step>
  <Step title="Заполнить название, slug и описание">
    - **Название** — введите понятное читателям наименование рубрики, например «Новости компании» или «Аналитика».
    - **Slug** — укажите короткий адрес рубрики для URL, например `novosti` или `analitika`. Система может сгенерировать slug автоматически, но рекомендуется проверить его вручную.
    - **Описание** — необязательное поле; текст отображается на странице рубрики над списком статей и помогает читателям понять тематику раздела.
  </Step>
  <Step title="Сохранить рубрику">
    Нажмите **Сохранить**. Новая рубрика сразу становится доступна при редактировании статей.
  </Step>
</Steps>

## Добавление тегов

Теги создаются непосредственно в редакторе статьи — отдельного раздела для их предварительного создания не требуется. Такой подход делает работу с тегами быстрой и гибкой.

При редактировании статьи найдите поле **Теги** в правой панели настроек. Начните вводить ключевое слово — система покажет список уже существующих тегов, начинающихся с введённых символов. Выберите подходящий тег из списка или нажмите **Enter**, чтобы создать новый. Вы можете добавить к одной статье любое количество тегов. Чтобы удалить тег из статьи, нажмите значок «×» рядом с его названием.

<Info>
  Все когда-либо созданные теги хранятся в системе и доступны для повторного использования. Просмотреть полный список тегов и при необходимости удалить неиспользуемые можно в разделе **Блог → Теги**.
</Info>

## Использование фильтров читателями

На публичной странице блога посетители портала видят панель фильтрации, которая помогает им сузить список публикаций до интересующей темы. Читатель может выбрать рубрику из меню навигации блога — страница обновится и покажет только статьи выбранной рубрики. При нажатии на тег внутри статьи или в облаке тегов блога отображаются все публикации с этой меткой. Фильтры по рубрике и тегам можно комбинировать, уточняя выборку. URL при каждом выборе обновляется, поэтому читатель может поделиться ссылкой на уже отфильтрованный список статей.

<Tip>
  Придерживайтесь принципа «не более 7–10 рубрик» для всего блога. Слишком разветвлённая структура рубрик запутывает читателей и усложняет навигацию. Если темы пересекаются — используйте теги для дополнительной детализации вместо создания новых рубрик.
</Tip>
