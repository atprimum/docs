Медиабиблиотека — это единое хранилище всех файлов, которые используются на вашем корпоративном портале. Загрузите изображение, документ или видео один раз — и вставляйте их в любые страницы, записи блога или статьи базы знаний без необходимости повторной загрузки. Все файлы хранятся в структурированном виде и доступны для поиска прямо из редактора контента.

## Поддерживаемые форматы

Медиатека портала принимает файлы наиболее распространённых форматов, разделённых на три категории.

<CardGroup cols={2}>
  <Card title="Изображения" icon="image">
    **JPEG / JPG** — фотографии и иллюстрации с потерями при сжатии.

    **PNG** — изображения с прозрачностью и без потерь.

    **WebP** — современный формат с высоким качеством и малым весом.

    **SVG** — векторная графика для логотипов и иконок.
  </Card>
  <Card title="Документы" icon="file-pdf">
    **PDF** — отчёты, презентации, инструкции и договоры.

    **DOCX** — редактируемые документы Microsoft Word.
  </Card>
  <Card title="Видео" icon="video">
    **MP4** — универсальный видеоформат с поддержкой во всех браузерах. Подходит для обучающих роликов, приветственных видео и демонстраций.
  </Card>
  <Card title="Прочие файлы" icon="file">
    Портал также поддерживает загрузку файлов **XLSX**, **PPTX** и архивов **ZIP** — для хранения шаблонов и раздаточных материалов.
  </Card>
</CardGroup>

## Загрузка файлов

Загрузить файлы в медиатеку можно как из отдельного раздела медиабиблиотеки, так и непосредственно из редактора страниц.

<Steps>
  <Step title="Откройте медиабиблиотеку">
    В левом меню администратора выберите раздел **Медиатека**. Вы увидите все ранее загруженные файлы в виде сетки или списка. Для переключения вида используйте иконки в правом верхнем углу.
  </Step>
  <Step title="Нажмите «Загрузить»">
    Нажмите кнопку **+ Загрузить** в правом верхнем углу страницы. Откроется диалоговое окно загрузки.
  </Step>
  <Step title="Выберите файлы">
    Перетащите файлы в область загрузки или нажмите **Выбрать файлы** для открытия проводника. Вы можете загружать несколько файлов одновременно — они добавятся в очередь.
  </Step>
  <Step title="Подтвердите загрузку">
    Убедитесь, что все файлы в очереди отображаются корректно, и нажмите **Загрузить**. По завершении загрузки файлы появятся в медиатеке и станут доступны для использования на страницах портала.
  </Step>
</Steps>

<Warning>
  Максимальный размер одного файла — **50 МБ**. Файлы большего размера система не примет. Перед загрузкой видео или объёмных PDF оптимизируйте их: сожмите видео до приемлемого качества, а из PDF уберите лишние шрифты и высококачественные вставки. Это также ускорит загрузку страниц для посетителей.
</Warning>

## Организация файлов

По мере роста числа материалов важно поддерживать порядок в медиатеке. Портал предоставляет несколько инструментов для этого.

<Accordion title="Папки">
  Создавайте папки для логического разделения файлов по темам, проектам или типам контента. Например: `Логотипы`, `Фото команды`, `Документы 2024`. Чтобы создать папку, нажмите **+ Новая папка** в боковой панели медиатеки. Перенесите файлы в нужную папку перетаскиванием или через контекстное меню.
</Accordion>

<Accordion title="Поиск по файлам">
  Используйте строку поиска в верхней части медиатеки, чтобы быстро найти нужный файл по имени. Поиск работает по всем папкам одновременно. Для точного результата вводите полное или частичное название файла без расширения.
</Accordion>

<Accordion title="Сортировка и фильтрация">
  Отсортируйте файлы по дате загрузки, имени или размеру — кнопка сортировки находится над сеткой файлов. Используйте фильтр по типу файла (изображения, документы, видео), чтобы быстро найти нужную категорию среди большого числа материалов.
</Accordion>

## Использование файлов в контенте

Чтобы вставить файл из медиатеки в страницу или публикацию, нажмите кнопку **Добавить медиа** в редакторе контента. Откроется окно медиатеки — найдите нужный файл и нажмите **Вставить**. Изображения отобразятся сразу в тексте, а документы и видео — в виде блоков с предварительным просмотром.

<Tip>
  Перед загрузкой изображений давайте файлам осмысленные имена на латинице, например `team-photo-2024.jpg` вместо `IMG_0042.jpg`. Это упрощает поиск в медиатеке и улучшает SEO-показатели страниц, на которых используются изображения.
</Tip>
